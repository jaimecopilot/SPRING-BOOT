# Proyecto acumulativo M5

Evoluciona el snapshot M4-R1 sin eliminar funcionalidad heredada. Añade una jerarquía de excepciones de aplicación, respuestas de error tipadas con `traceId`, `@RestControllerAdvice` ordenados, perfiles `dev/test/prod`, `@ConfigurationProperties` y CORS global externalizado por perfil.

Baseline: Java 17, Spring Boot 3.5.16 y Maven Wrapper 3.9.16.
