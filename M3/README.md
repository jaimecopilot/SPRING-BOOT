# M3 - Desarrollo de APIs REST con Spring Boot

Módulo acumulativo construido sobre M2. Incluye teoría, 6 prácticas con 72 pasos, proyecto final ejecutable, colección Postman y PDFs.

## Contenido

- `TEORIA.md`: GET, POST, PUT/PATCH, DELETE, DTOs/validación y parámetros/cabeceras/Postman.
- `PRACTICA.md`: 72 pasos reproducibles (12 por punto).
- `proyecto/`: snapshot final acumulativo.
- `postman/`: colección y entorno locales.
- `M3_TEORIA.pdf` y `M3_PRACTICA.pdf`: edición maquetada.

## Baseline

Java 17, Spring Boot 3.5.16 y Maven Wrapper 3.9.16.
