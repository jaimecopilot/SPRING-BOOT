# Módulo 3 — Desarrollo de APIs REST con Spring Boot

## Qué hace este módulo

M3 amplía la aplicación estructurada en M2 hasta convertirla en una API REST más completa y verificable. El foco pasa de la arquitectura interna al contrato HTTP que ofrece la aplicación.

## Qué aprenderás

- Diseño e implementación de operaciones `GET`, `POST`, `PUT`, `PATCH` y `DELETE`.
- Diferencias entre colección y recurso individual.
- Uso de DTOs y validación de entrada.
- Parámetros de ruta, parámetros de consulta y cabeceras HTTP.
- Construcción de respuestas y códigos de estado adecuados.
- Pruebas del contrato REST.
- Uso de Postman para documentar y verificar la API.

## Qué construyes

Evolucionas el proyecto de M2 hasta disponer de un CRUD REST completo, validado y documentado, con colección Postman y un contrato HTTP preparado para incorporar persistencia real en M4.

M3 continúa desde M2. M4 conserva el contrato REST y sustituye la persistencia en memoria por JPA/Hibernate.
