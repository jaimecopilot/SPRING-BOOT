# Curso Spring Boot 2026

Repositorio del curso completo Spring Boot 2026.

## Módulos disponibles

- [`M0`](M0/): preparación del entorno y primer proyecto Spring Boot.
- [`M1`](M1/): introducción a Spring Boot y arquitectura back-end.
- [`M2`](M2/): creación y estructura de proyectos Spring Boot.
- [`M3`](M3/): desarrollo de APIs REST con Spring Boot.
- [`M4`](M4/): persistencia de datos con JPA / Hibernate.
- [`M5`](M5/): gestión de errores y configuración avanzada.
- [`M6`](M6/): seguridad con Spring Security y JWT.
- [`M7`](M7/): proyecto global standalone: API REST de gestión de becas.

## Estructura de cada módulo

Cada módulo contiene, según corresponda:

- `TEORIA.md`: guía teórica del módulo;
- `PRACTICA.md`: guía práctica paso a paso;
- PDFs de teoría y práctica;
- `proyecto/`: código ejecutable asociado al módulo;
- ejemplos, tests y recursos adicionales necesarios para reproducir la práctica.

## Validación y auditoría

La infraestructura interna de trazabilidad, auditoría y evidencias vive separada en `.course/` y `.github/` y no forma parte del recorrido principal del alumno.

Los módulos publicados actualmente son **M0 a M7**.
