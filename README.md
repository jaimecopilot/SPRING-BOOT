# Curso Spring Boot 2026

Repositorio del curso completo Spring Boot 2026.

## Módulos disponibles

- [`M0`](M0/): preparación del entorno y primer proyecto Spring Boot ejecutable.
- [`M7`](M7/): proyecto global integrador standalone de gestión de becas, con teoría, práctica reproducible, proyecto ejecutable y PDFs.

Cada módulo contiene:

- `TEORIA.md`: guía teórica;
- `PRACTICA.md`: guía práctica paso a paso;
- `proyecto/`: código ejecutable asociado al módulo;
- ejemplos adicionales cuando son necesarios para reproducir la práctica.

La infraestructura de validación y auditoría vive separada en `.course/` y `.github/` y no forma parte del recorrido del alumno.

Los PDF se publican por separado para teoría y práctica.
