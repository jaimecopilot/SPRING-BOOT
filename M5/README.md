# M5 - Gestión de errores y configuración avanzada

Módulo acumulativo sobre el cierre canónico M4-R1. Mantiene JPA/Hibernate y la API existente y añade una política explícita de errores, configuración externalizada y CORS.

- Fuente: páginas 986-1202 del PDF del curso.
- Teoría: 5 puntos, 25 bloques y 75 subpuntos teóricos de fuente.
- Práctica: 60 pasos fuente.
- Proyecto: Java 17, Spring Boot 3.5.16 y Maven Wrapper 3.9.16.
- Trazabilidad: esquema v3, continuidad M4 -> M5, reversibilidad y mutation gate.

Consulta `TEORIA.md`, `PRACTICA.md` y `CODESPACES.md` para estudiar y ejecutar el módulo.
