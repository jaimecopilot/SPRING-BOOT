# M6 SNAPSHOT CONTRACT

El código de M6 se publica por puntos prácticos, no como un único proyecto final.

```text
M5/proyecto
 -> M6/6.1/proyecto
 -> M6/6.2/proyecto
 -> M6/6.3/proyecto
 -> M6/6.4/proyecto
 -> M6/6.5/proyecto
 -> M6/6.6/proyecto
 -> M6/6.7/proyecto
 -> M6/6.8/proyecto
 -> M6/6.9/proyecto
```

`M6/6.9/proyecto` es el único final oficial y será la base exacta de M7. `M6/proyecto` está prohibido. Cada snapshot debe construirse exclusivamente desde el anterior y superar sus gates antes de producir el siguiente.
