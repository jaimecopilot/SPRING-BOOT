# Source audit M6 — fidelidad editorial y reconstrucción

## Fuente canónica

- PDF: `SPRING BOOT PDF.pdf`.
- Intervalo M6: páginas 1203–1550 inclusive (348 páginas).
- Puntos: 6.1–6.9.
- Teoría: 45 bloques / 135 subpuntos.
- Práctica: 112 pasos.

## Método de esta edición

M6 se reconstruye **por bloques**, no mediante síntesis global. Para cada subpunto teórico y cada paso práctico se preserva el cuerpo de la fuente y se añade, cuando procede, una capa de actualización M6. Esto impide que el inventario de títulos dé un falso positivo de cobertura mientras desaparecen explicaciones o ejemplos.

La implementación final moderniza la fuente donde es necesario: Java 17, Spring Boot 3.5.16, `SecurityFilterChain`, `@MockitoBean`, JJWT 0.13.0, JWT stateless, secreto Base64 externalizado y errores de seguridad alineados con M5. El material histórico útil se conserva marcado; no se convierte en implementación final.
