# Auditoría editorial interna - M0

Este documento no forma parte del material del alumno. Comprueba que la nueva edición conserva el alcance y la profundidad pedagógica de la fuente sin exigir copia literal.

## Cobertura estructural

- Punto 0.1: JDK/JRE/JVM, bytecode, classpath, Maven, IDE, instalación, `JAVA_HOME`, `PATH` y diagnóstico.
- Punto 0.2: Spring Initializr, metadata, starters, POM, Maven Wrapper, importación y primera ejecución.
- Punto 0.3: estructura Maven/Spring Boot, clase principal, configuración, escaneo y controlador REST mínimo.
- Punto 0.4: arranque, logs, parada, depuración, tests, `curl`, empaquetado y cuatro recorridos operativos completos.

## Requisitos editoriales comprobados

- preguntas conservadas y acompañadas de respuestas razonadas;
- consola/terminal, IntelliJ IDEA, Eclipse y VS Code permanecen como recorridos explícitos cuando la operación cambia;
- no se introducen DTO, validación, JPA, seguridad u otros contenidos de módulos posteriores;
- el código final mostrado en la práctica coincide con los artefactos del repositorio;
- los estados temporales de diagnóstico se restauran antes del estado final;
- la trazabilidad interna no aparece dentro de `TEORIA.md` ni `PRACTICA.md`.
