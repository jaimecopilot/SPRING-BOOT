- Páginas fuente del intervalo: **221**.

## Método de recuento

Los recuentos de fuente se obtienen del binario PDF real suministrado, extrayendo texto de las páginas 461-681 con PyMuPDF. Las métricas de teoría y práctica se delimitan por los marcadores `PARTE TEÓRICA` y `PARTE PRÁCTICA` de cada uno de los seis puntos. Los caracteres se cuentan sobre el texto extraído normalizado únicamente para retirar caracteres de separación invisibles; las palabras se cuentan por tokens separados por espacio. Las páginas nuevas se cuentan sobre los PDFs finales renderizados, no sobre estimaciones.

## Fidelidad y modernización

La edición conserva los seis puntos, los treinta bloques teóricos, los setenta y dos pasos, retos resueltos, errores comunes, preguntas, resultados esperados y la secuencia pedagógica completa del PDF fuente. No se elimina silenciosamente contenido de alto valor.

Se moderniza y conecta con el snapshot ejecutable mediante:

- Java 17.
- Spring Boot 3.5.16.
- Maven 3.9.16 mediante el wrapper del curso.
- `@MockitoBean` en lugar de `@MockBean` cuando corresponde.
- Bean Validation con `jakarta.validation`.
- `ServletUriComponentsBuilder` para `Location`.
- separación DTO de entrada / salida.
- validación de 400 / 404 / 409 / 415 según el tipo de error.
- paginación, filtrado y ordenación verificables.
- soft delete y dependencias entre recursos como ejercicio de reglas de negocio.
- colección y entorno Postman exportables.
- regresión acumulativa de los endpoints heredados de M2.

- Pasos prácticos trazados: **72/72**.
